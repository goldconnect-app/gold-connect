# Gold Connect

Приложение к боту @GoldWGpay_bot. Защищённое зашифрованное подключение к вашей личной сети.

## Скачать

Установочные файлы выкладываются здесь:

https://github.com/goldconnect-app/gold-connect/releases

Для Android — файл `gold-connect-<версия>.apk`. Версии с пометкой Pre-release — для проверки, остальным лучше брать обычные.

## Как поставить на Android

Скачайте файл, откройте его и разрешите установку, если телефон спросит. Подключение настраивается через бота:

https://t.me/GoldWGpay_bot

## Как проверить файл

Рядом с каждым файлом лежит его контрольная сумма SHA-256 с окончанием `.sha256`, та же сумма указана в описании выпуска.
